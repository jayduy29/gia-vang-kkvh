Cách hoạt động:
  • Dữ liệu chung lưu tại data/gold.json trong repo GitHub — GitHub Action scrape bảng giá mỗi ngày lúc 14:00 (giờ VN) rồi commit; ai mở web cũng thấy cùng một dữ liệu, không phụ thuộc trình duyệt.
  • Khi bạn mở trang, app tự tải data/gold.json rồi gộp với bản ghi cục bộ (localStorage). Dữ liệu chung được GitHub Action cập nhật hằng ngày; nếu dữ liệu máy chủ quá cũ, app tự thử lấy giá mới trực tiếp.
  • Các công cụ nhập/xuất dữ liệu được ẩn sau nút ổ khóa và mật khẩu.
  • Giá website mang tính tham khảo, giao dịch theo bảng giá niêm yết tại cửa hàng.
